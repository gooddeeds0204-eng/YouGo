# YouGo Feature Map

YouGo is an original social voice-room product with feature coverage comparable to leading party-chat apps, while keeping its own branding and UI.

## Core social
- User profiles, follows, followers, profile visits
- Private messages, activity and requests
- Moments/social feed
- Search by user, room and family
- Families/clubs and family rankings
- Levels, badges, charm and wealth identity

## Persistent rooms
- One persistent room container
- Voice Mode
- Video Mode
- Game Mode
- Switching modes preserves room identity, audience, roles, chat, gifts, VIP state and event state
- Level 1 baseline: 8 seats
- Host/owner and admin roles from Level 1
- Open/locked seats
- Audience list
- Chat and announcements
- Music queue
- Room settings, seat settings, broadcast and member management
- Mute/audio controls and entry effects

## PK & games
- Room PK
- Game PK
- Diamond Hunt
- Spin & Win
- Greedy
- Eat Ball
- Lucky Dice
- Truth / Dare style social activity
- Configurable in-app reward tables and daily limits

## Economy
- Diamonds, coins and event tokens
- Recharge entry point
- Gift shop
- Couple gifts
- Luxury gifts
- Gift collection
- Wallet
- Cosmetic store
- Inventory/bag
- Avatar frames
- Vehicles
- Chat bubbles
- Entry effects
- Room themes

## VIP & progression
- VIP center
- VIP avatar frames, entry effects, vehicles, chat styling and badges
- User level progression
- Room unlocks by level
- Daily and weekly missions
- Login/activity streaks
- Reward inventory

## Events & leaderboards
- Monthly themed events
- Event tokens
- Top 5 gift leaderboard
- Host, room and family rankings
- Charm and wealth rankings
- Event missions and limited cosmetics

## In-room rewards
- Lucky Pocket
- Diamond Hunt
- Spin & Win
- Reward diamonds, points, cosmetics, event tokens and free spins
- No cash-out rewards in the current product design

## Safety
- Blocked users
- Report flows
- Privacy controls
- Room moderation roles
- Age/safety settings placeholder

## Current implementation status
The GitHub build currently provides a high-fidelity interactive UI prototype for the above systems. Real authentication, database state, realtime chat, voice/video media, payments and production game logic require backend integration in the next implementation phases.
