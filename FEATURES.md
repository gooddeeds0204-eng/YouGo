# YouGo — Complete Interactive Prototype Feature Map

YouGo is an original party-social app design inspired by the feature breadth of modern voice-chat communities, with its own branding, UI and product rules.

## 1. Account & onboarding
- Welcome/onboarding experience
- Mobile-number + OTP demo flow
- Demo mode for prototype testing
- Profile identity, user ID, follow/follower counts
- Settings, notifications, language and account/security placeholders

## 2. Social discovery
- Discover by country, language, topic and room type
- Voice, Video, Game, Music and social-room categories
- Search by room ID, user, family and interests
- Follow/unfollow people
- Share room flow
- Notifications center
- Profile visitors

## 3. Profiles & Moments
- User profile with level, VIP, diamonds and charm
- Upgraded profile photo wall
- Photos, short videos, highlights and achievements
- Moments feed for photos, jokes/status and short videos
- Likes/comments presentation
- Achievement badges and titles

## 4. Private chat
- 1:1 chat UI
- Text messages
- Image sharing entry point
- Voice-note entry point
- Voice/video call placeholders
- Online/VIP/level identity in chat

## 5. Persistent party room
- One persistent room container
- Voice Mode
- Video Mode
- Game Mode
- Mode switching preserves room identity, roles, audience, chat, gifts, VIP and event state
- Level 1 baseline: 8 seats
- Higher room progression: 12, 16, 20 and up to 27 seats
- Owner/host and admin/moderator roles from Level 1
- Open, occupied and locked seats
- Premium avatar frames and role badges
- Audience strip
- Chat composer and live room feed
- Room announcement and broadcast
- Room sharing
- Lucky Chest / room reward entry point

## 6. Room management
### Basic
- Members
- Room settings
- Seat settings
- Broadcast
- Member management
- Admin/moderator roles

### Audio & safety
- Individual mic toggle
- Mute-all controls
- New-seat mute preference
- Speaker/music/gift/entry sound sliders
- Noise suppression placeholder
- Echo cancellation placeholder
- Block, remove, mute and report flows

## 7. Entertainment
- Room PK
- Game PK
- Music queue
- Ludo
- UNO-style card game
- Diamond Hunt
- Spin & Win
- Greedy
- Eat Ball
- Lucky Dice
- Truth / Dare social activity

Game rewards in the prototype are in-app only: reward diamonds, coins, points, event tokens, cosmetics and free spins.

## Prototype status

The repository now contains a feature-complete **interactive UI prototype** for the product map above. GitHub Actions automatically validates JavaScript syntax and required feature markers.

Production systems still require backend/service integration for:
- Real authentication and OTP delivery
- Persistent database state
- Realtime private/room chat
- Real voice/video media
- Push notifications
- Real image/video uploads
- Payment/recharge processing
- Server-authoritative gift balances
- Live PK/game state and matchmaking
- Moderation backend and report processing
