# YouGo App Blueprint

This document freezes the high-level product structure.

## Main areas

- Authentication and onboarding
- Home and discovery
- Profiles, Moments and private chat
- Persistent Voice / Video / Game rooms
- Gifts, wallet, recharge and store
- VIP / SVIP / levels / achievements
- Couple and Family systems
- Events, rankings, missions and daily check-in
- Plug-in games and cosmetic modules
- Safety, moderation and reporting

See `ARCHITECTURE.md` for code boundaries and `FEATURE_STATUS.md` for implementation progress.
